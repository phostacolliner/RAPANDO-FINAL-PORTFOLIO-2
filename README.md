# Colliner Phosta — Portfolio Website
**Data Analyst | Economist | Researcher | Business Intelligence Professional**

A production-ready personal brand and portfolio website for **Colliner Phosta**, meticulously recreating the provided executive dark-navy and cyan design system with interactive charts, dynamic project filters, data lab simulators, and research insights.

---

## 🌟 Key Features

1. **Executive Hero Section**:
   - Matches the reference visual layout with high-contrast typography, title, bio, and CTA buttons.
   - Background futuristic analytics visualization panels, 78% donut progress KPI, sparklines, and handwritten signature.
2. **Interactive Data Lab**:
   - Built with **Recharts**: dynamic sales and profit scenario analysis (Bear / Base / Bull), Kenya macroeconomic CPI inflation time-series breakdown, and regional revenue share.
3. **Featured Projects**:
   - Dynamic category filtering (*All, Data Analytics, Finance, Economics, Research, Web Development*).
   - Project cards with modal view showing problem statements, objectives, methodology, tools, findings, business impact, and code/demo links.
4. **Services & Capabilities ("What I Do")**:
   - 5 service cards for Data Analytics, Financial Analytics, Econometrics & Economic Analysis, Research & Evaluation, and Web & Software Development.
5. **Research & Economic Insights**:
   - Working papers and articles with modal reader, abstract, empirical dataset source, and policy implications.
6. **Skills & Academic History**:
   - Visual proficiency indicators and Kirinyaga University Bachelor's Degree in Economics and Statistics (2020 – 2024).
7. **Contact & Lead Form**:
   - Validated contact form with clickable phone (`0722450893`), email (`phostacolliner@gmail.com`), LinkedIn, and GitHub.
8. **CV Download**:
   - Interactive preview and instant structured CV document generation.

---

## 🛠️ Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Custom Dark Glassmorphism, Google Fonts (`Plus Jakarta Sans`, `Caveat`, `JetBrains Mono`)
- **Data Visualization**: Recharts (AreaChart, LineChart, BarChart, PieChart)
- **Icons**: Lucide React

---

## 🚀 Quickstart & Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

---

## 📁 Customizing Content & Assets

- **Portrait Image**: Place your portrait at `/public/assets/colliner-phosta.png` or replace the image in `src/assets/images/`.
- **CV PDF**: Place your PDF file at `/public/assets/Colliner-Phosta-CV.pdf`.
- **Projects**: Edit `src/data/projects.ts` to add or modify project case studies.
- **Services**: Edit `src/data/services.ts`.
- **Research Papers**: Edit `src/data/research.ts`.
- **Skills**: Edit `src/data/skills.ts`.
- **Contact Info**: Edit `src/components/Contact.tsx`.
